One funny line, 86 characters: I ask an AI to write my apology letter, and the AI apologizes to me — for having to write it.

The joke turns on who owes whom an apology: the tool hired to say sorry ends up demanding the sorry itself. Nothing is borrowed — no robot-uprising gag, no "as an AI" wink — and the reversal lands in the second clause, so the line reads smoothly aloud and the laugh comes from the machine's sudden, very human resentment.
